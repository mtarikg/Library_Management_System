## Library Management System (LMS)

This console-based Library Management System (LMS) is implemented in Python using an object-oriented approach and a simple .txt file as a database. 
It demonstrates core Python skills, class design, method implementation, file I/O, and analytical thinking, with a focus on maintainable code and design considerations rather than a full-scale production system.

### Key Features:
- Listing all books
- Adding a book
- Removing a book
- A console-based user interface

### Additional Highlights:
- Complexity analysis of methods (adding/removing books)
- Identification of potential bugs and suggestions for improvement
- Emphasis on maintainable code structure and design considerations
- Version control with Git to track changes
